# dalia — тренажёр китайского языка

Сайт: https://daliastudy.ru/

## Как теперь определяется «Изучено»

- Один правильный ответ **не** отмечает карточку как изученную.
- Автоматическая отметка появляется после **трёх разных календарных дней**, в каждый из которых был хотя бы один правильный ответ на эту карточку **без подсказок и помощи**. Несколько ответов в один день дают только один день прогресса.
- На ещё не изученных карточках отображается «в изучении · 1/3 дня» или «2/3 дня». Дни практики сохраняются в `studyDays` в существующем `localStorage` с ключом `dalia_state_v7`.
- Неверные ответы и ответы с подсказками не добавляют дней. Они продолжают влиять на обычную статистику ошибок и расписание повторений.
- Кнопка «Изучить» остаётся ручной отметкой для слов, которые пользователь уже знает. Снятие отметки в карточке или коллекции обнуляет только эти три дня, **не стирая историю ответов и повторений**.
- Существующие отметки «Изучено» оставлены без изменений, поскольку старые данные не позволяют различить ручные отметки и старый автоматический способ. Все прежние записи ответов, карточки, избранное и резервные копии совместимы.
- Экспорт, импорт и переименование пользовательских карточек поддерживают новый `studyDays`.

## Офлайн-работа

Основные файлы кэшируются сервис-воркером `sw.js`. После обновления версии кэша новые правила изучения загружаются из последней опубликованной версии сайта. Для внешних сервисов озвучки, распознавания или написания может потребоваться интернет.
