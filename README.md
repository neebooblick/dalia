# Dalia 8.0.7

## Изменения
- Выражения из 200 записей «Мудрости» исключены из общего словаря, случайных карточек и тренировок. Сама вкладка «Мудрость» и её каталог сохранены.
- Размер окна «Случайная карточка» зафиксирован. Длинные примеры прокручиваются внутри окна, не меняя его высоту; при переходе к следующему слову прокрутка возвращается наверх.
- Звуки интерфейса стали существенно тише, короче и светлее. Убраны нисходящие ноты при ошибке. Звук сферы остаётся независимым от переключателя звуков.

## Обновление
Замените файлы сайта. Данные прогресса остаются в localStorage с прежним ключом. Перед обновлением рекомендуется экспортировать резервную копию.

## 8.0.6
Звуки интерфейса получили по четыре тихих варианта на действие, включая сферу. Звуковая палитра осталась светлой и ненавязчивой; громкость не повышали. Настройка отключения обычных звуков сохранена, сфера звучит независимо.

## 8.0.7 — исправления стабильности и интерфейса
- Защита загрузки каталога от некорректных форматов локального прогресса и повреждённых карточек, включая перенос данных старых версий.
- При нажатии на сердечко обновляется только оно, а не весь список: клавиатурный фокус и положение прокрутки сохраняются.
- Обновлены заголовок страницы и версия офлайн-кэша для получения свежей версии.
