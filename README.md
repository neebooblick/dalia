# Dalia 8.1.1 — оптимизация скорости (01.11.2026)

- CSS, данные словаря и основная логика вынесены из index.html в отдельные версионированные статические файлы.
- Скрипты загружаются с `defer` в исходном порядке: сначала словарь, затем приложение; интерфейс можно отрисовать до выполнения JS.
- Service Worker заранее кеширует новые ресурсы и обновляет кеш атомарно при активации.
- В открытии карточки больше не создаётся весь словарь заново. Ускорены подсчёт статистики и показ длинного каталога.
- Ключ localStorage `dalia_state_v7`, формат резервных копий и алгоритм изучения не изменены.
- Индивидуальный прогресс повторений в интерфейсе скрыт, кнопка «Изучить» сохранена.
- При последующем редактировании словаря или логики необходимо обновлять версию файлов и список SHELL в sw.js.

# Dalia 8.0.8 — каталог расширен

## Новые простые слова (29.10.2026)
- Добавлено 111 повседневных карточек (еда, дом, семья, действия, погода, время, места и простые выражения).
- Каждая карточка имеет пиньинь, значение, китайский пример и русский перевод.
- Все слова проверены на дубли и синхронизированы с `VOCABULARY.csv`. Ключ сохранения прогресса не изменён.

## Изменения
- Выражения из 200 записей «Мудрости» исключены из общего словаря, случайных карточек и тренировок. Сама вкладка «Мудрость» и её каталог сохранены.
- Размер окна «Случайная карточка» зафиксирован. Длинные примеры прокручиваются внутри окна, не меняя его высоту; при переходе к следующему слову прокрутка возвращается наверх.
- Звуки интерфейса стали существенно тише, короче и светлее. Убраны нисходящие ноты при ошибке. Звук сферы остаётся независимым от переключателя звуков.

## Обновление
Замените файлы сайта. Данные прогресса остаются в localStorage с прежним ключом. Перед обновлением рекомендуется экспортировать резервную копию.

## 8.0.6
Звуки интерфейса получили по четыре тихих варианта на действие, включая сферу. Звуковая палитра осталась светлой и ненавязчивой; громкость не повышали. Настройка отключения обычных звуков сохранена, сфера звучит независимо.

## 8.0.7 — исправления стабильности и интерфейса
- Защита загрузки каталога от некорректных форматов локального прогресса и повреждённых карточек, включая перенос данных старых версий.
- При нажатии на сердечко обновляется только оно, а не весь список: клавиатурный фокус и положение прокрутки сохраняются.
- Обновлены заголовок страницы и версия офлайн-кэша для получения свежей версии.

## 8.0.8 — интерфейс
- Переработано окно настроек: секции, типографика, кнопки, отступы и мобильная компоновка.
- После ответа в упражнениях можно нажать на отдельный вариант: появляется карточка с иероглифом, пиньинем, переводом и озвучкой. Другие варианты не раскрываются автоматически.
- В случайных карточках кнопка «Следующая» находится в неподвижной шапке окна. Длинные примеры прокручиваются независимо.
- Версия офлайн-кэша обновлена для получения новых файлов.

## 8.1.0 — освоение слов в разные дни (01.11.2026)
- Один правильный ответ **не** отмечает карточку как изученную. Автоматическая отметка ставится после правильных ответов **без подсказок в три разных календарных дня**; повторные ответы в тот же день не ускоряют прогресс.
- Индивидуальные этапы изучения не отображаются пользователю, но сохраняются для интервальных повторений.
- Ручная отметка «Изучить» остаётся доступной. Снятие отметки сбрасывает только зачтённые дни, не историю ответов.
- Сохранён старый прогресс: существующие «Изученные», карточки, оценки, интервалы, избранное. В экспорт и импорт добавлено поле `studyDays` в прежнем `localStorage`.
